# Syllable Bakery 🥐🧁

An interactive, engaging phonetic learning game and pastry kitchen built with React, TypeScript, and Tailwind CSS designed to help students master syllable segmentation, word blending, and phonics through bakery-themed challenges.

## Features

- **Four Interactive Bakery Games**:
  - **Ingredient Sort**: Listen to grocery words and sort them into syllable-count mixing bowls.
  - **Measure Match**: Match syllable cards with correct visual recipe measurement items.
  - **Recipe Writer**: Fill in the missing decodable words in step-by-step baking recipes.
  - **Mix & Move**: Tap syllable blocks to mix delicious bakery treats.
- **Level Quizzes**: 10-question quizzes for Level 1 (up to 3 syllables) and Level 2 (up to 5 syllables) with randomized non-repeating questions.
- **Trophy Case & Celebration**: Earn badges and trophies with pastry confetti and celebratory sound effects.
- **Audio & Accessibility**: Built-in speech synthesis (`SpeechSynthesis API`) and custom Web Audio synthesizer for delightful sound effects.

## Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18+) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/syllable-bakery.git
   cd syllable-bakery
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## GitHub Pages Deployment

This repository is configured with relative base paths (`base: './'`) in Vite, making it ready for static hosting and GitHub Pages deployment.
